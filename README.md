# 2D Space Shooting Game — C++ & OpenGL Arcade Engine

A 2D arcade space combat game built from scratch in **C++** utilizing **OpenGL**, **GLSL Shaders**, **GLFW**, and **Assimp**.

## ?? Gameplay & Architecture
- **Kinematic Projectile Physics:** High-speed bullet trajectory simulation and collision checks.
- **Wave-based Enemy AI:** Dynamic enemy spaceship spawning, pursuit vectors, and health management.
- **GLSL Shaders:** Custom vertex & fragment shaders for textured models and lighting effects.
- **Asset Pipeline:** 3D model loading via Assimp and texture mapping via \stb_image\.

## ??? Built With
- **Language:** C++
- **Graphics API:** OpenGL / GLSL
- **Windowing & Input:** GLFW / GLEW
- **Model Loader:** Assimp

## ?? How to Run
1. Open \Lab6.sln\ in **Visual Studio 2022**.
2. Select **Release / x64** or **Debug / x64**.
3. Press **F5** to build and launch!
